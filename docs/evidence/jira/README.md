# Jira delivery acceptance evidence

These dedicated sandbox captures cover Jira Cloud and Data Center in English and Vietnamese, exact provider-ready previews, finding links, settings and the console state matrix in Light and Dark themes. The original 82 captures and 20 additional selected-security-level captures are indexed below; the manifest pins all 102 published PNG files. PNG conversion preserved the original decoded JPEG pixels.

Actual Jira captures establish rendered content and completed delivery. The readonly views use a real restricted role. Controlled local API faults exercise console loading, empty and error states. Playground captures illustrate recovery controls with simulated records; automated fake-provider and durable-store tests establish timeout, crash and uncertain recovery behavior.

The first four actual intents demonstrate audited administrator security waivers. Cloud uses the optional provider default Medium in those historical examples; Data Center maps High and resolves its required Reporter from the authenticated identity. Four additional restricted tickets select security level 10000 (Synapse Restricted) and map priority High in both deployments. Each has one intent, one attempt, one unique correlation match and one finding link. Mapping version 2 governs these new commands; the previous completed snapshots remain unchanged.

The selected-security-level captures show actual Cloud and Data Center tickets and exact console previews in English and Vietnamese, in Light and Dark. Cloud displays its checked security-level popover; Data Center displays the level in Details. [Recorded REST/API observations](security-selection.json) independently compare summary, provider-ready description, priority, project, issue type, labels and security against the stored preview. Cloud ADF is compared structurally with object key order ignored; Data Center wiki text is compared exactly. The record identifies the acceptance runtime binaries and distinguishes live create evidence from later breaker-reset tests. Preview screenshots were captured after delivery by recomputing the same unchanged mapping/finding preview; they are not a recording of a pre-submit browser click.

No customer data or configured credential is included. Production recovery objectives, broad browser coverage and assistive-technology conformance are outside this evidence.


## Selected issue security level

These new synthetic findings use the reporter-only Synapse Restricted level, without a waiver. In `security-selection.json`, `checks.waiver: true` means the assertion that no waiver was used passed; it is not a raw waiver value. All four records select security level `10000`. The older waiver samples below retain their original provenance. No screenshot was composed, cropped, recolored or otherwise altered; PNG conversion preserves decoded JPEG pixels.
