# Jira delivery acceptance evidence

These dedicated sandbox captures cover Jira Cloud and Data Center in English and Vietnamese, exact provider-ready previews, finding links, settings and the console state matrix in Light and Dark themes. All 82 images were read during acceptance review; the manifest pins the published PNG bytes. PNG conversion preserved the original decoded JPEG pixels.

Actual Jira captures establish rendered content and completed delivery. The readonly views use a real restricted role. Controlled local API faults exercise console loading, empty and error states. Playground captures illustrate recovery controls with simulated records; automated fake-provider and durable-store tests establish timeout, crash and uncertain recovery behavior.

The four actual intents completed with one attempt, one correlation match and one finding link each. The sandbox projects use audited administrator security waivers. Cloud priority uses the optional provider default Medium; Data Center maps High and resolves its required Reporter from the authenticated identity.

No customer data or configured credential is included. Production recovery objectives, broad browser coverage and assistive-technology conformance are outside this evidence.
